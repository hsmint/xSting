ROS 2 Launch xsting_bringup Single GPU Container (vision)

xSting Bringup 실행 옵션 가이드

기준 파일: xsting_bringup/launch/xsting.launch.py · 불리언 인자는 대소문자 구분 없이 true / 1 / yes / on을 활성화로 인식합니다.
실행 순서와 센서·로봇팔·신호등 현장 보정 방법은 실행 및 현장 보정 통합 가이드 (run_and_calib_guide.html)를 참고하세요.

1. 실행 명령어 생성기 (CLI Builder)

ros2 launch xsting_bringup xsting.launch.py

2. 전체 실행 옵션 상세 (총 14개)

인자명 분류 타입 기본값 실행·제어 대상 노드 역할 및 세부 동작
urdf 로봇 모델·TF bool true robot_state_publisher
static_odom_tf (조건부)		 xsting.urdf를 로드하여 로봇의 정적·관절 TF를 발행합니다.
• slam:=false일 때 urdf:=true이면 RViz 좌표계 유지를 위해 odom → base 정적 TF도 자동 발행합니다.
joint_states 로봇 모델·TF bool true joint_state_publisher 외부 하드웨어의 관절 상태 입력 없이도 joint_order.yaml의 기본 서기·팔 접힘 자세로 6족 다리·팔·Arducam TF를 완성합니다.
• 전제 조건: urdf:=true일 때만 동작합니다. 실기체 하드웨어 노드가 /joint_states를 발행할 때는 false로 끕니다.
realsense 카메라·LiDAR 센서 bool true realsense_camera
realsense_splitter		 전면(camera) RealSense 드라이버를 구동하고, IR 에미터 On/Off 프레임을 분리해 SLAM(에미터 Off)과 Depth 매핑·PCA(에미터 On)으로 공급합니다.
arducam 카메라·LiDAR 센서 bool true arducam_camera 로봇팔에 장착된 Arducam 카메라 영상의 GPU 디코딩 및 렌즈 왜곡 보정 노드를 실행합니다.
lidar 카메라·LiDAR 센서 bool true coin_d4_lidar
lidar_odom		 1층 중앙 천장형(Roll = 180°) 2D LiDAR 드라이버(coin_d4_driver)와 본체·6족 다리 실시간 마스킹·근접 벽 2D ICP 오도메트리 보정·nvblox 점군 변환 노드를 함께 실행합니다.
lidar_port 카메라·LiDAR 센서 string /dev/lidar coin_d4_lidar COIN-D4(LDS-03) 2D LiDAR 시리얼 포트 경로를 지정합니다 (99-lidar.rules udev 심볼릭 링크 기본값 /dev/lidar).
• 전제 조건: lidar:=true일 때 적용됩니다.
slam SLAM·매핑 bool true visual_slam_node
nvblox_node		 전면 camera 기반 cuVSLAM(위치 추정)과 nvblox(카메라 + 2D LiDAR TSDF/ESDF 장애물 매핑) 노드를 함께 실행합니다.
• 비활성화(false) 시 urdf:=true이면 odom → base 정적 TF로 대체됩니다.
imu SLAM·매핑 bool false visual_slam_node cuVSLAM의 추적 모드(tracking_mode)를 전환합니다.
• false: 스테레오 카메라 단독 추적 (tracking_mode: 0)
• true: VIO 카메라 + IMU 융합 추적 (tracking_mode: 1)
• 전제 조건: slam:=true일 때 적용됩니다.
imu_topic SLAM·매핑 string /imu visual_slam_node visual_slam/imu 입력을 리매핑할 IMU 토픽 이름을 지정합니다.
• 전제 조건: slam:=true 및 imu:=true 사용 시 실질적으로 활용됩니다.
map_3d SLAM·매핑 bool true nvblox_node nvblox의 3D 메시·복셀 레이어 연산 여부를 제어합니다.
• true: 2D ESDF(10 Hz) + 3D 메시(5 Hz) + 레이어(1 Hz), 최대 높이 2.0 m
• false: 메시·레이어 주기를 0.0 Hz로 끄고 최대 높이를 0.6 m로 제한해 주행용 2D ESDF 슬라이스(0.01~0.5 m)만 경량 계산합니다.
• 전제 조건: slam:=true일 때 적용됩니다.
yolo AI 비전 인식 bool true camera 전처리 인코더
tensor_rt · yolov8_decoder
depth_pca 		전면 camera에 대해 TensorRT(rg_nano_batch1_640_fp16, 5클래스) 추론·디코딩(/camera/color/detections)과 3D 위치·주축 추정 노드(depth_pca)를 실행합니다.
sign AI 비전 인식 bool true sign_yolo/tensor_rt
sign_yolo/yolov8_decoder
sign_barcode 		신호등·표지판 전용 TensorRT(sign_nano_batch1_640_fp16, 4클래스, /sign_yolo/detections)와 바코드 Action 노드(sign_barcode)를 실행합니다.
• yolo:=false여도 sign:=true이면 전면 camera 전처리 인코더를 자동 생성합니다.
foxglove 시각화·브리지 bool false foxglove_bridge 비전 컨테이너와 분리된 독립 프로세스로 Foxglove WebSocket 브리지(포트 8765)를 실행합니다. 화이트리스트 정규식으로 비압축 원본 영상·내부 텐서·대용량 nvblox 맵 토픽을 자동 제외하여 대역폭을 보호합니다.
rviz 시각화·브리지 bool false rviz2 xsting_bringup/config/xsting.rviz 레이아웃 설정으로 로컬 RViz2 시각화 창을 실행합니다.

3. 프로세스 구조 및 주요 의존성

컨테이너 vs 독립 프로세스 배치

  • 단일 GPU 컴포넌트 컨테이너 (vision): realsense, arducam, slam(cuVSLAM·nvblox), yolo, sign 관련 모든 노드가 멀티스레드 컨테이너 하나에 적재되며 use_intra_process_comms: True 제로카피 통신으로 동작합니다.
  • 독립 프로세스 노드: robot_state_publisher, joint_state_publisher, static_odom_tf, foxglove_bridge, rviz2는 비전 파이프라인 지연 방지를 위해 별도 프로세스로 실행됩니다.

알아두면 좋은 옵션 간 연계 규칙

  • slam 하위 옵션: imu, imu_topic, map_3d는 모두 slam:=true일 때만 효력이 있습니다.
  • yolo와 sign의 텐서 공유: yolo:=true이면 이미 생성된 camera 전처리 텐서를 sign_yolo가 그대로 구독해 GPU 중복 연산을 피합니다.
  • CPU 아키텍처 자동 분기: TensorRT 엔진 파일은 실행 환경에 따라 model/arm64/ 또는 model/x86_64/ 경로가 자동 선택됩니다.

4. 상황별 추천 실행 예시

① 실주행 최적화 + 원격 Foxglove 모니터링 추천 (실기체 주행)
3D 메시 생성을 꺼서 GPU 부하를 줄이고(map_3d:=false), 하드웨어 관절 상태 충돌을 막기 위해 가상 joint_states를 끄며 원격 관제용 Foxglove 브리지를 켭니다. 
ros2 launch xsting_bringup xsting.launch.py map_3d:=false joint_states:=false foxglove:=true
② 로컬 디버깅 및 3D 공간 매핑 확인 디버깅·시각화
기본 옵션(3D 맵 map_3d:=true 포함)을 모두 켠 상태에서 로컬 RViz2를 함께 실행합니다. 
ros2 launch xsting_bringup xsting.launch.py rviz:=true
③ IMU 융합(VIO) SLAM 활성화 VIO 모드
빠른 회전이나 특징점이 적은 구간에서 cuVSLAM 안정성을 높이기 위해 IMU 토픽을 융합합니다. 
ros2 launch xsting_bringup xsting.launch.py imu:=true imu_topic:=/imu
④ SLAM 제외 비전(카메라 + YOLO + 표지판) 단독 테스트 비전 단독
SLAM/nvblox 없이 객체·표지판 인식만 검증합니다. urdf:=true이므로 odom → base 정적 TF가 자동 유지됩니다. 
ros2 launch xsting_bringup xsting.launch.py slam:=false rviz:=true
⑤ 신호등 · 바코드 단독 테스트 (Foxglove 전용 레이아웃) 신호등·바코드
전면 RealSense + 신호등 YOLO + 바코드 Action만 띄우고 Foxglove(xsting_foxglove_sign.json)로 실시간 확인합니다. 
ros2 launch xsting_bringup xsting.launch.py realsense:=true sign:=true foxglove:=true arducam:=false lidar:=false slam:=false yolo:=false
